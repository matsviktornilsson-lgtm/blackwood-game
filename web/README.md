# Blackwood web prototype

A visual technical scaffold, not yet a playable tower defence game. It tests a 3D cliff, orthographic camera, one starting window, lighting, a fenced outer defence line, and animated werewolves that run from the forest to the fence when night starts. No Blender or backend is required.

```sh
npm install
npm run dev
```

Use `npm run build` to validate and create `dist/`. For Cloudflare Pages Git integration, set **root directory** to `web`, **build command** to `npm run build`, and **output directory** to `dist`. The app has not been deployed yet.
